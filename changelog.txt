CHANGELOG: P2P SESSION SYNC MIGRATION
Branch: webRTC_session-transfer
Date: 2026-04-29

OVERVIEW:
Replaced the unstable WebRTC (PeerJS) handshake logic with a robust, 100% serverless QR-Data transfer system. Optimized for performance on Chromebooks and reliability across different network environments.

1. CORE SYNC ARCHITECTURE
- Removed all PeerJS/WebRTC dependencies (signal servers, handshake logic, STUN/TURN).
- Implemented "Progress-Only" sync: The QR code now carries the actual session data.
- Optimized data payload using Bitsets (binary representation of deck state).
- Integrated LZString compression to ensure 300+ card sessions fit in a single QR code.

2. UI/UX REFINEMENTS
- Renamed icon 'send2phone.svg' to 'cast.svg' for better semantic meaning.
- Implemented Orientation-Adaptive Header:
  - Portrait (Vertical): Full-width header for maximum studying space.
  - Landscape (Horizontal/Desktop): Pill-shaped floating header.
- Dynamic Mobile Header:
  - Shows 'Download/Import' button when Score is 0.
  - Automatically hides Import button and shows Score counter once progress begins.
- Performance: Removed high-GPU 'glow/pulse' animations from the QR modal to prevent lag on Chromebooks.

3. IN-GAME SCANNING
- Integrated 'html5-qrcode' library.
- Added a built-in camera scanner modal to allow syncing without leaving the webapp.
- Added HTTPS detection and security warnings for camera permissions.

4. LOGIC & CLEANUP
- Refactored 'transfer.js' to be a standalone, serverless module.
- Updated 'game.js' to handle real-time UI state updates for the new header logic.
- Purged all residual WebRTC diagnostic logs and UI elements.

FILES MODIFIED:
- pages/game.html (Header structure, library imports, scanner modal)
- js/transfer.js (Complete rewrite: compression, bitset logic, QR generation, scanning)
- js/game.js (Score display logic, UI toggle integration, cleanup)
- assets/img/cast.svg (New icon)
- assets/img/download.svg (Updated usage)

5. REFINED SESSION TIMELINE & EXPANDED STATS METRICS ('pages/stats.html', 'js/stats.js')
- Linha do Tempo da Sessão (Reversed & Capped at 10):
  - Configured timeline flow to display strictly the last 10 answers answered in the session.
  - Ordered with the most recent card on the far left with a pulsing active ring and tooltip indicators.
  - Header dynamically updates with counter label ('← Mais recentes (X de Y respondidos)').
- Previsão de Conclusão & Ritmo Cognitivo:
  - Calculates estimated remaining study time based on current session pace and cards left in the pool.
  - Tracks fastest card answer time (⚡ recall imediato) and slowest card answer time (⏳ reflexão aprofundada).
- Índice de Domínio do Baralho (Mastery Score):
  - Computes an aggregate mastery score (0-100 pts) based on deck progress (40%), session accuracy (45%), and streak bonus (15%).

- Destaques de Estudo (Marca-texto Analytics):
  - Tracks the number of cards in the deck containing highlighted keywords and total highlights applied.
  - Displays a breakdown by pastel color: Amarelo, Verde, Azul e Roxo.
- Comparativo de Rendimento Sessão a Sessão:
  - Pedagogical diagnostic compares current session accuracy with the previous session (+X% vs sessão anterior) to detect growth or fatigue.
- Recorde de Sequência Histórica:
  - Displayed in the All-Time KPIs grid on the History tab ('Recorde de Sequência: 🔥 X').

6. GEMINI FLASH-LITE AI CATEGORIZATION FOR DECKS & TOPICS ('pages/stats.html', 'js/stats.js', 'js/stats-ai.js')
- Semantic Categorization via Function Calling:
  - Uses Gemini Flash-Lite with structured tool calling ('salvar_categorizacao_estudos') to classify decks and cards simultaneously in a single API roundtrip.

- Desempenho por Assuntos no Baralho Atual:

  - Also mirrored in the Historical Sessions tab ('tab-content-history') for all-time subject review.
- Seamless AI Activation & Inactive State:
  - When AI is not active or no API key is set, no API calls are made; displays a sleek skeuomorphic placeholder card with the button 'Gerar estatísticas de IA' and API key input.
  - Includes in-place configuration modal to update or clear the Gemini API Key, with offline and local caching in 'flashcards_ai_categories'.
